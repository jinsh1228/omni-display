# Third-party resources

The cockpit door extends Create SlidingDoorBlock and uses Create SlidingDoorRenderer.
Door model, texture and sound resources are referenced at runtime from the separately installed Create mod.
The cockpit_door blockstate mapping is adapted from Create 6.0.10 brass_door.json.

## Optional Create: Radars integration (test21)

Compiled against the user-provided Create: Radars 0.4.9.4-1.21.1 JAR by Aycer, HappySG, CeoOfGoogle, Kipti, OndatraCZE, and Ray(furuochen). The radar mod must be installed separately; its code, models, textures and JAR are not included. This integration calls its classes and reads its existing connection/target state.
