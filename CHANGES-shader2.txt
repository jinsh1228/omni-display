Omni Display 1.1alpha-shader2 — 显示面 HUD 与动态门遮罩实验版

基于 shader1，保留 Photon2 的接缝绘制和通用光影历史隔离。

改动：
1. 分区模式下，球形 HUD 和雷达框仅显示在当前可见显示面覆盖的像素中；门洞、非显示面与被前景挡住的位置裁掉 HUD。
2. shader2fix 中舱外观察者也可以看到内侧显示面上的仪表。雷达框保留外部地形不遮挡的规则，F1 下 HUD/雷达仍保留。
3. 滑动门开关动画中的透视遮罩沿用门模型的滑动距离、向外偏移和当前动画进度，上下半扇读取同一扇门的动画。
4. 不再在 OPEN 状态刚切换时整扇移除透视遮罩。完全打开后的残留门板保持原处理，不增加显示面识别。
5. 活板门保持原处理。F8 的旧版整舱模式仍使用原 HUD 绘制，不启用新的显示面裁剪。

验证：Java 21 编译、20 项 Java 检查与资源打包检查通过。
新增门遮罩开关连续性检查；GPU 实际 HUD 着色器检查确认显示面像素显示、非显示面像素丢弃。
原有遮挡合成、Photon/Voxy 深度、纹理及 SSBO 复制 GPU 检查通过。
没有进入 Minecraft 实测，尤其移动载具上的门板遮罩与光影深度仍需实测确认。

安装：关闭游戏，用 omni-display-1.1alpha-shader2.jar 替换旧 Omni Display；mods 仅保留一个版本。
保留原光影和设置，F8 开启分区模式。
重点测试：从舱内看门洞应没有 HUD/雷达框；屏幕上仍有；座椅等前景阻挡时 HUD 裁掉。
慢速开门、关门和中途反向；四个朝向、左右铰链、上下门板；移动和旋转中的载具。
完全打开后的残留门板保持原样。F1 下仪表仍显示；出舱后可以透过门洞观察内侧屏幕仪表。
若异常可回退 shader1，并保留 latest.log、光影名称和复现情况。

通用光影实验的限制仍在：其他光影的抖动、内部缩放、远景深度等尚未逐个适配；双遍渲染和资源快照增加 GPU 与显存开销。
没有修改光影包、用户配置或游戏安装目录。
