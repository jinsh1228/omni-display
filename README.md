# Omni Display 1.3alpha

基于 1.2 的优化实验版。不可见屏幕跳过第二次绘制，并缓存屏幕面及座舱识别信息。使用和测试说明见 [RELEASE_1_3ALPHA.md](RELEASE_1_3ALPHA.md)。

基于 1.1alpha-shader2fix。Minecraft 1.21.1 / NeoForge；不包含 1.2alpha 的虚拟摄像机或六面合成。

## 服务器统一渲染设置

游戏内“模组 → Omni Display → 配置”（或 F8）提供低性能模式设置。默认使用显示面分区渲染，门洞保留正常画面；开启低性能模式后恢复整舱透视与门互锁，并禁用开放式座舱、手动分组和滤镜。滤镜提供强度滑条和冷色调、像素纹理、扫描线、屏幕边缘四个独立开关；默认强度 0%，0% 即关闭。

设置保存在世界的 `serverconfig/omni_display-server.toml`：`lowPerformanceMode = false`。单人世界主人或权限等级 2 及以上管理员可在游戏内修改，普通客户端不能自行切换。配置页不会暂停世界，以便单人服务器处理修改。独立服务器可停服后编辑配置文件。

1.3alpha 本轮补回滤镜独立开关，新增破坏后的渲染自动恢复，以及关节结构和普通 Create 轴承运动结构上的屏幕分组。详见 [RELEASE_1_3ALPHA.md](RELEASE_1_3ALPHA.md)。

当前使用方法、座舱选择工具、高光工具、兼容范围及安装说明见 [RELEASE_1_2.md](RELEASE_1_2.md)。下面保留此前兼容修补的记录。

## 关联结构与粒子

可选适配 Synaxis 1.5.0：服务器读取物理连接图并同步 UUID 关系，客户端与已有 Sable 方块依赖合并识别整个关节链。支持固定、自由、旋转和通用物理约束，排除地面、禁止碰撞和无关结构；断开关系后恢复显示。Synaxis 不新增为必需前置。

粒子记录出生时所属载具，透视画面中按载具不透明度处理；不透明度为 0 时跳过其绘制。舱内保留区域、普通视野及门洞画面中的粒子继续正常绘制。粒子只做渲染过滤，不改变寿命和物理运动。使用原版粒子透明度的烟雾等可随设置渐变；特殊模组自行绘制且不使用标准粒子入口的效果仍需实测。

## 验证与安装

编译、逻辑/资源检查及实际 OpenGL 遮罩合成检查通过；未进行游戏实测。已验证安装环境的粒子调用目标和 Synaxis 接口。服务器与客户端都需更新，替换旧 Omni Display JAR，避免重复安装。

重点测试：普通模式开门拒绝开机、开机锁门；开启实验模式开门运行；关闭实验模式时恢复互锁；普通玩家只读配置；同船粒子消失但门洞仍可见；Synaxis 多级关节结构透视、断开后恢复。

## 营火烟雾修补（版本号仍为 1.1alpha2）

检测到整合包安装 AsyncParticles 21.1.4.0-beta.3，并开启 GPU 粒子加速。原版 ParticleEngine 绘制过滤不会经过其 GPU 绘制路径。新增可选适配：出生于载具的粒子走 CPU 粒子队列，以便普通画面和透视画面分别过滤；其他粒子继续使用原 GPU 加速。Sable 将粒子从载具局部坐标转换为世界坐标前再次记录归属，避免烟雾脱离载具后丢失来源。无需修改 AsyncParticles 的配置或光影包。安装后需要重启游戏，清除旧 GPU 队列中的粒子。

## Photon 云层与生物黑尾实验修补（仍为 1.1alpha2）

仅对名字含 photon-voxy-support 的光影生效。模组在内存中的 Photon 云层和 AO 片段程序中加入透视画面开关：云层强制使用较强的邻域历史校正，并将额外历史混合权重限制为 0.85；环境光遮蔽历史混合权重限制为 0.2。普通画面保持原权重。未关闭阴影、体积云或整套 TAA，也不修改光影包 ZIP。

此修补是减少拖影的试验，未游戏实测；可能增加云层和 AO 的少量噪点，最终 TAA 或实体运动历史仍可能产生残影。替换 JAR 并重启后，对比实验渲染开关，观察纯转头时云层、生物移动时黑尾及门洞普通画面。

## 启动冲突修补

错误报告 2026-10-01 18:18:31 显示粒子过滤与 AsyncParticles 的 ParticleEngine 覆盖方法都使用优先级 500，Mixin 因优先级检查拒绝注入。粒子过滤恢复为优先级 1000，允许作用于优先级 500 的覆盖方法；同时移除对 Sable 合并方法的额外注入，继续使用构造时及 GPU 分流前的粒子来源捕获。版本号保持 1.1alpha2。

## 云层第二次试验修补

上一版只加强历史裁剪仍未阻止 Photon 的棋盘重建直接沿用旧像素。本次只在实验性透视画面中对当前帧低分辨率云颜色与距离数据做四点空间插值，并使云历史失效，跳过棋盘旧像素复用和云时序累积。普通视野的云仍使用原重建方式，已有效的 AO 修补保持不变。整体 TAA 保留，光影包文件不变。云层可能稍软或有噪点；尚未游戏实测。
